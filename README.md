# Carlos Kei Primicias Muyot — First Birthday Invitation

A personalised, responsive starter website inspired by the invitation video. It uses a navy, cream and muted-gold palette, tartan-style corners/ribbon, script headings, baby-photo area, music player, countdown, event details, health protocol, monetary-gift section, RSVP and closing panel.

## Personalised details already set
- Name: Carlos Kei Primicias Muyot
- Event: First birthday
- Date: Sunday, 13 December 2026
- Time: 12 noon
- Venue: Sierra Hotel, Dumaguete
- Google Maps search link: Sierra Hotel Dumaguete

## Add your own files
Copy these into `assets/`:
- `baby-photo.jpg` — a high-resolution photo of Carlos Kei
- `venue.jpg` — Sierra Hotel photo or a venue photo you have permission to use
- `music.mp3` — chosen music you have permission to use

The website will show designed placeholders until the photos are added. The original teddy-bear illustrations, exact floral decorations, exact fonts and music from the reference video have not been extracted; those assets are needed for a closer match.

## Preview
Extract the ZIP and open `index.html` in a browser. If your browser restricts local assets, run a local web server or publish to a static hosting provider.

## Before sharing with guests
1. Add your baby's photo, venue photo and music.
2. Choose the exact RSVP deadline.
3. Decide whether to add a gift registry link.
4. Connect the RSVP form to Google Forms, Formspree, or a backend. Currently, it downloads an RSVP text file in the guest's browser; it does not deliver responses to you.
5. Test the site on mobile and desktop.

## Hosting
You can publish the static website using Netlify or GitHub Pages. You do not need Canva to run the website; Canva can be used to create/export decorative artwork or image assets. The site itself is HTML/CSS/JavaScript.
